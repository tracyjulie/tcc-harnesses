# Starter: ReservaFácil (aplicação full-stack)

Base minima para o cenario de complexidade alta. Contem apenas a stack (React + TypeScript + Vite no frontend; Hono com `node:sqlite` no backend, a ser implementado pelo agente). Nao contem a solucao, migracoes, dados iniciais nem testes.

- Node.js: 22.23.3 (requer `node:sqlite`, disponivel sem compilacao nativa)
- Comandos: `npm ci`, `npm run build`
